# Bagify 👜🛍️

Bagify is a **full-stack web-based shopping application** developed to digitalize traditional bag shop operations by providing an **online platform for browsing, purchasing, and managing branded bags**.

The system simplifies manual shop processes by offering **online product management, cart handling, order processing, payment support, and automated report generation using Crystal Reports**.

---

## 🎯 Project Overview

The Bag Shop system focuses on:

- Online shopping for branded bags  
- Category-wise product browsing  
- Secure order and payment processing  
- Admin-controlled shop management  
- Automated order reports using Crystal Reports  
- Reduced paperwork and manual workload  

---

## 👥 User Roles

The system supports **three main user roles**:

---

### 1️⃣ Admin
Admin manages the complete system and shop operations.

**Responsibilities:**
- Secure admin authentication  
- Manage product categories  
- Add, update, and delete products  
- View and manage customer orders  
- Generate **ordered products reports using Crystal Reports**  
- Handle customer enquiries and feedback  

---

### 2️⃣ User
A visitor who browses the website and registers.

**Actions:**
- View product categories  
- Browse available products  
- Register and login  
- Send enquiries  

---

### 3️⃣ Customer
A registered user who can purchase products.

**Actions:**
- Browse products by category  
- View detailed product information  
- Add products to cart  
- Place orders  
- Make payment (Cash on Delivery / Online)  
- View order history  
- Submit feedback
