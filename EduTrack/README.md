# 🎓 EduTrack - Classroom & Student Management Portal

EduTrack is a backend-driven classroom and student management system designed to simplify academic operations such as student record handling, batch management, and administrative workflows using scalable REST APIs.

The system focuses on improving efficiency by digitizing manual processes and providing a structured backend architecture for educational platforms.

---

## 🎯 Project Overview

EduTrack system focuses on:

* Student record management
* Batch and classroom management
* RESTful API-based architecture
* Secure and scalable backend services
* Efficient handling of academic data using NoSQL database

---

## 👥 User Roles

The system supports the following roles:

### 1️⃣ Admin

Admin manages the overall system operations.

**Responsibilities:**

* Manage student records (Add, Update, Delete)
* Create and manage batches
* Monitor system data
* Ensure proper data handling and operations

---

### 2️⃣ Student

Students are managed within the system by admin.

**Actions:**

* View assigned batch details
* Access their academic information
